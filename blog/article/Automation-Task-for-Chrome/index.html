Chrome Options and Driver

A ChromOptions object is instantiated as follows:

1from selenium import webdriver
2options = webdriver.ChromeOptions()

Available methods of ChromeOption object can be found in the documentation of Selenium . Common usages:

  • for .add_argument, for a list of arguments we refer to here.

    For example, if we want to maximize the window on chrome launched, then write option.add_argument("--start-maximized").

  • for preference, we use .add_experimental_option, for a list of preferences we refer to here. I am not sure whether .set_preference would override the default preference.

In our case we want to specify the default download directory (which cannot be changed after the Driver object is instantisated):

1options = webdriver.ChromeOptions()
2prefs = {"download.default_directory" : f"{os.getcwd()}/download"}
3options.add_experimental_option("prefs", prefs)

Now we build our driver using our options.

1browser = webdriver.Chrome(executable_path=DRIVER_PATH, chrome_options=options)

Implicit Wait

From the documentation of Selenium implicit-wait is:

An implicit wait tells WebDriver to poll the DOM for a certain amount of time when trying to find any element (or elements) not immediately available. The default setting is 0 (zero). Once set, the implicit wait is set for the life of the WebDriver object.

We will discuss explicit-wait later in the discussion of downloading files.

In my situation I choose to wait for 10 seconds as dom elements may take time to render:

1browser.implicitly_wait(10)

Select Element and Click

In case an automation task can be done where every desired dom element can be selected by id attribute, we define the following util function:

1def get_el_by_id(id):
2  el = browser.find_element_by_id(id)
3  assert el is not None, f"Element of id: {id} cannot be found"
4  return el

A list of methods to find dom element(s) can be found here.

Buttons

Selecting a button and click is as simple as:

1submit_btn = get_el_by_id("butSubmit")
2submit_btn.click()
Dropdown List and Selection

We can select an element in dropdown list by using their value attribute:

1from selenium.webdriver.support.select import Select
2
3# dropdown_id: the id of the dropdown dom element
4# target_value: the value attribute of our target
5selection_list = Select(get_el_by_id(dropdown_id))
6selection_list.select_by_value(target_value)

Download Files and Explicit Wait

As usual we select an element that would trigger download action and click it:

1confirm_btn = get_el_by_id("downloadBtn")
2confirm_btn.click()

Next we look at the download directory:

1import time
2
3def every_downloads_chrome(browser):
4  if not browser.current_url.startswith("chrome://downloads"):
5    browser.get("chrome://downloads/")
6  return browser.execute_script("""
7    var items = document.querySelector('downloads-manager')
8        .shadowRoot.getElementById('downloadsList').items;
9
10    if (items.length == 0) {
11      return ["no_download"]
12    }
13
14    if (items.every(e => e.state === "COMPLETE")) {
15        return items.map(e => e.fileUrl || e.file_url);
16    }
17    """)
18# waits for all the files to be completed and returns the paths
19
20time.sleep(4)
21# timeout for 2 minutes
22paths = WebDriverWait(browser, 120, 1).until(every_downloads_chrome)
23assert len(paths) >= 1 and paths[-1] != "no_download", "No file is being downloaded"
24# get the name of lastly downloaded file:
25latest_download_filename = paths[-1].split("/")[-1]
26
27# print the downloaded file
28for filepath in paths:
29  print(f"Files donwloaded: {filepath}")

Points to note:

  • Since website may have a delay after clicking the download button, we wait for 4 seconds to make sure there is a file to be downloaded.

  • We also handle the case that the server has an internal error that ruins our download process. In this case, we return ["no_download"] when items.length == 0.

    Note that the return value [] wouldn't stop the waiting process by experiment.

Documentation for WebDriverWait: https://selenium-python.readthedocs.io/api.html?highlight=WebDriverWait.
